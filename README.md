Healthcare Performance Analysis Dashboard

Project Overview

This project focuses on analysing healthcare data across multiple facilities to identify patterns in patient admissions, diagnoses, laboratory tests and hospital performance.

The goal is to transform raw healthcare data into meaningful insights that can support data-driven decision-making.

Project Objectives

- Analyse patient admission patterns.
- Identify the most common medical diagnoses.
- Examine patient distribution across different departments and facilities.
- Analyse laboratory test distributions and results.
- Compare healthcare service utilisation across states.
- Evaluate patient length of stay across facilities.

Tools Used

- Microsoft Excel – Data cleaning and preparation.
- Microsoft Power BI – Data modelling, analysis and dashboard visualisation.

Data Cleaning and Preparation

The dataset was prepared and cleaned using Microsoft Excel.

The process involved:

- Identifying and handling missing values.
- Checking duplicate records.
- Identifying invalid age values.
- Standardising inconsistent entries.
- Preparing date fields for analysis.

Dashboard Visualisations

The Power BI dashboard includes:

- Patient and healthcare performance KPIs.
- Most common diagnoses.
- Monthly admission trends.
- Laboratory test distribution.
- Test result distribution.
- Patient distribution by state and diagnosis.
- Department and facility performance analysis.

Project Deliverables

- Cleaned healthcare dataset (Excel).
- Interactive Power BI dashboard (.pbix).
- Dashboard screenshots.

Conclusion

This project demonstrates the use of data cleaning, analysis and visualisation techniques to explore healthcare data and communicate meaningful findings through an interactive dashboard.
